# Locally hosted type assets

UI: **DM Sans**, paired with system **Georgia** for editorial display.
Indic fallbacks: **Noto Sans Devanagari** and **Noto Sans Gurmukhi**.
Arabic, CJK and Cyrillic use the documented system stacks in `css/tokens.css`.

These are static font assets, not JavaScript runtime dependencies. Nothing is
requested from Google when the app runs. WOFF2 files are unmodified downloads.

Source CSS retrieved 10 October 2026:
