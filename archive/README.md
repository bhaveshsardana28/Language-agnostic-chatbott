# Archive — "Aikya" Streamlit prototype (not part of the submission)

This folder preserves, unmodified, an earlier prototype built on a different
architecture (Streamlit UI delegating answers to external LLM APIs).
It does **not** implement the pivot-translation + single-English-intent-model
design of the final-year project and is kept only for reference/history.
The reusable modules (`detection.py`, conceptually `translation.py`) were
promoted to `src/`; everything else here is retired.
