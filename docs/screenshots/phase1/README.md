# Phase 1 design-study screenshots

These screenshots show **static, illustrative design directions**, not the
working assistant, real model responses, speech recognition or voice support.

Capture targets: directions A/B/C × welcome/chat/voice × 360/1440 px, plus the
comparison index at both widths. A/B explore light-first palettes; C explores a
dark-first palette. The chosen direction's deliberately designed pair of themes
belongs to Phase 2 onward.

See `../../design-explorations/README.md` for the verification record and run
instructions. Filenames identify the direction, screen and viewport width.
