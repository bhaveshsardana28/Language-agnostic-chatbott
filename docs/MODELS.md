# Model and service inventory

| Component | Runtime | Input and output | Limits |
|---|---|---|---|
| Language identification | Local langdetect plus script and Romanized Hindi/Punjabi heuristics in `src/detection.py` | Each message produces a language, heuristic confidence, script shares and possible secondary languages | A heuristic score is not a calibrated probability. The detection benchmark covers six languages. |
| Machine translation | Bounded requests to the Google mobile translation page and MyMemory HTTPS endpoint | Translates explicitly requested text. Inline/fenced code and URLs are preserved. | External quotas, network and web-page changes can interrupt translation. The disk cache can contain private text. |
| Chat generation | Configured Groq, OpenAI-compatible or local Ollama endpoint | System instructions, recent turns, user question and optional retrieved context produce streamed text | Configure the provider and its model together. Input memory is bounded by turns. The default generation budget is 1024 tokens. |
| Document retrieval | Local sentence-transformers with `paraphrase-multilingual-MiniLM-L12-v2` and CPU PyTorch | Document chunks and questions produce multilingual embeddings. NumPy ranks by similarity. | First use requires a cached model or a download. A new session can fall back to keyword retrieval. Broad overview and point questions use different selection rules. |
| Document storage | SQLite plus generated original-file paths | Persists extraction metadata, chunk text and vectors by workspace/conversation | Cached indexes are bounded and keyed by committed revision. Treat the runtime as a single-node application. |
| OCR | Local Tesseract using pytesseract, Pillow and PyMuPDF | Images and low-text PDF pages produce extracted text, quality metadata and warnings | Requires the selected language packs and a host OCR engine. English synthetic fixture results appear in the test report. |
| Voice | Browser recognition and local-voice speech synthesis | Dictation writes an editable draft. Listen reads a completed reply on demand. | Recognition may use the browser vendor's service. Installed voices and real-device accuracy vary. |

The Groq catalog returned HTTP 200 and listed the configured `qwen/qwen3.8-27b` during this audit. Subsequent synthetic chat tests exercised generation and streaming. The current operator can compare availability with the [Groq model catalog](https://console.groq.com/docs/models). Other provider adapters need a live smoke test with their own model configuration.
